# GitHub Followers Analyzer 📊

Простой и эффективный скрипт на Python для анализа ваших подписчиков и подписок на GitHub, использующий официальный REST API GitHub.

Скрипт поможет быстро привести профиль в порядок, выявив:
*   **Взаимные подписки** — пользователи, которые подписаны на вас, и на которых подписаны вы.
*   **Односторонние подписки** — пользователи, на которых подписаны вы, но которые не подписаны на вас в ответ.
*   **Поклонники (фанаты)** — пользователи, которые подписаны на вас, но на которых вы не подписаны в ответ.

## ✨ Возможности

*   **Полный сбор данных:** Автоматическая обработка пагинации API GitHub позволяет получать списки любого размера (даже если в них более 100 пользователей).
*   **Прямые ссылки:** Результаты выводятся в виде кликабельных ссылок на профили пользователей.
*   **Безопасность и лимиты запросов:** Скрипт может работать как без авторизации (до 60 запросов в час), так и с использованием персонального токена доступа (GitHub Personal Access Token), что позволяет обойти ограничения по количеству запросов.

## 🚀 Начало работы

### 1. Подготовка окружения

Убедитесь, что у вас установлены Python 3.x и библиотека `requests`. Если библиотека еще не установлена, выполните команду:

```bash
pip install requests
```

### 2. Настройка скрипта

Откройте файл скрипта и отредактируйте константы в его начале:

```python
# Укажите ваше имя пользователя на GitHub
USERNAME = "Your_Username"

# (Опционально) Введите ваш персональный токен доступа (GitHub Personal Access Token),
# если у вас большое количество подписчиков или подписок.
# Оставьте пустой строкой "", если хотите использовать скрипт без токена.
TOKEN = ""
```

> **Примечание:** Если общее количество ваших подписчиков и подписок превышает объем данных, умещающийся на 60 страницах, GitHub заблокирует запросы, выполняемые без токена авторизации. Чтобы создать токен, перейдите в раздел *Settings -> Developer Settings -> Personal access tokens -> Tokens (classic)* и сгенерируйте токен, предоставив ему как минимум разрешение **`read:user`**. ### 3. Запуск

Запустите скрипт через терминал или командную строку:

```bash
python main.py
```

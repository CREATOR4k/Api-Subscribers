# GitHub Followers Analyzer 📊

Простой и эффективный Python-скрипт для анализа ваших подписчиков (`followers`) и подписок (`following`) в GitHub с использованием официального GitHub REST API.

Скрипт помогает быстро навести порядок в профиле, выявляя:
*   **Взаимных друзей** — пользователей, с которыми у вас взаимная подписка.
*   **Невзаимные подписки** — тех, на кого подписаны вы, но кто не подписан на вас в ответ.
*   **Фанатов** — пользователей, которые подписаны на вас, но вы не подписаны на них.

## ✨ Особенности

*   **Полный сбор данных:** автоматически обрабатывает пагинацию GitHub API, выкачивая списки любой длины (более 100+ пользователей).
*   **Прямые ссылки:** выводит результат в виде готовых кликабельных ссылок на профили пользователей.
*   **Безопасность и лимиты:** может работать без авторизации (до 60 запросов в час) или с GitHub Personal Access Token для обхода ограничений.

## 🚀 Инструкция по запуску

### 1. Подготовка окружения

Убедитесь, что у вас установлен Python 3.x и библиотека `requests`. Если библиотеки нет, установите её:

```bash
pip install requests
```

### 2. Настройка скрипта

Откройте файл скрипта и отредактируйте константы в начале файла:

```python
# Укажите свой логин на GitHub
USERNAME = "Ваш_Логин"

# (Необязательно) Вставьте ваш GitHub Token, если у вас много подписок/подписчиков.
# Оставьте пустой строкой "", чтобы запустить без токена.
TOKEN = ""
```

> **Примечание:** Если у вас суммарно (подписки + подписчики) больше 60 страниц данных, GitHub заблокирует запросы без токена. Для создания токена перейдите в *Settings -> Developer Settings -> Personal access tokens -> Tokens (classic)* и сгенерируйте токен с минимальным правом **`read:user`**.

### 3. Запуск

Запустите скрипт через терминал или командную строку:

```bash
python main.py
```
